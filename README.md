# Institutional Options Intelligence Platform

Analytics-only institutional options terminal (no order execution).

## Stack
- Frontend: Next.js 15 + TypeScript + Tailwind + Zustand
- Backend: FastAPI
- Realtime/DB: Supabase

## MVP Order
1. Frontend layout
2. Strategy builder
3. Payoff graph
4. Greeks
5. Option chain
6. WebSocket updates
7. Market intelligence
